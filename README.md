# Практическая работа
## Цель практической работы
Освоить создание интерактивных финансовых приложений в Streamlit, реализовав кредитный калькулятор с расчётом платежей и детальным графиком погашения.

### Что нужно сделать
Задача — реализовать собственный кредитный калькулятор.

Необходимо написать приложение на Python с использованием streamlit, которое будет обладать следующим функционалом:
- считывание суммы кредита, процентной ставки, срока кредита и типа платежа по кредиту (аннуитетный и дифференциальный);
- вычисление ежемесячного платежа по кредиту (для аннуитетного типа);
- формирование графика платежей по кредиту в виде таблицы со следующими столбцами:
- остаток долга,
- ежемесячный платеж,
- процентная часть,
- долговая часть,
- остаток долга на конец периода;

Дополнительно (факультативно):
- считывание даты первого платежа и добавление в таблицу даты каждого из платежей;
- обработку случаев неправильного ввода;
- использование механизмов условного рендеринга (if/else, st.expander(), st.rerun() и st.stop()).
